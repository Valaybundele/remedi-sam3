# ReMeDI-SAM3 — Project Page

Project website for the MICCAI 2026 paper:

**ReMeDI: Refined Memory for Disambiguation of Identities with SAM3 in Surgical Segmentation**
Valay Bundele, Mehran Hosseinzadeh, Hendrik P. A. Lensch — University of Tübingen

ReMeDI-SAM3 is a training-free extension of SAM3 for occlusion-robust surgical instrument segmentation, combining relevance-aware and occlusion-aware memory, memory expansion via piecewise interpolation of temporal positional encodings, and feature-based re-identification with temporal voting. Evaluated zero-shot on EndoVis17, EndoVis18, and CholecSeg8k.

Code: https://github.com/cgtuebingen/remedi-sam3
